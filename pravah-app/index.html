Features List

  • Unified API workbench for HTTP, GraphQL, gRPC, WebSocket, MQTT, and SOAP protocol workflows.
  • Burp-like request and response catch/inspect panel with body, headers, raw, and timeline switching for deep debugging.
  • Request collections and execution history sidebars for repeatable testing and team-level organization.
  • Rich response analysis panel with status, duration, body, headers, raw payload, timeline, and test outputs.
  • Environment profile support to swap base URLs and variables across dev, QA, and production contexts.
  • Integrated auth, headers, body, tests, and scripts tabs to keep full request lifecycle in one screen.
  • Desktop architecture with React + Tauri UI, FastAPI orchestrator, and Rust executor services.
